# Raum für Klang – Design V1

Dieser Ordner enthält einen eigenständigen, statischen Mehrseiten-Prototyp für die gestalterische Abnahme.

## Seiten

- `index.html` – Startseite
- `klangbehandlungen/index.html` – Unterseite Klangbehandlungen

## Lokal ansehen

Im Repository-Stamm:

```bash
python3 -m http.server 8080
```

Danach öffnen:

- `http://localhost:8080/design-v1/`
- `http://localhost:8080/design-v1/klangbehandlungen/`

## Zweck dieses Schnitts

Der Prototyp trennt die künstlerische Entscheidung von der technischen Integration in den bestehenden Editor. Nach der gestalterischen Freigabe werden Seitenaufbau, Bildplätze und Designsystem in den gemeinsamen Website-Renderer, die Vorschau und den Export übernommen.

Es werden keine externen Schriften, Skripte, Bilder oder Trackingdienste geladen.
